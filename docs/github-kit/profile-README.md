# Hi, I'm Al-Nahiyan Khushbu 👋

**PhD researcher in Artificial Intelligence** · Southwest Jiaotong University, Chengdu, China

I build **hybrid CNN-Transformer models for medical imaging**, focused on detecting
Parkinson's disease early from structural MRI, before motor symptoms appear.
