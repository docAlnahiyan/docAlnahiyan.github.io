medical imaging and early Parkinson's disease detection.

## Tech stack

React · Vite · Tailwind CSS. Deployed with GitHub Pages from the `gh-pages` branch.

## Repository layout

```
.
├── index.html        # entry page: SEO meta, Open Graph, schema.org Person data
├── assets/           # compiled Vite bundle (JS + CSS)
├── favicon.svg
├── 404.html          # redirects unknown URLs back to the home page
├── robots.txt
├── sitemap.xml
├── .nojekyll         # serve files as-is, skip Jekyll processing
└── docs/github-kit/  # templates for the GitHub profile and research repos
```

> **Note:** this branch holds the *built* site only. The React source lives outside this
> repository; see [`docs/github-kit/ORGANIZATION_GUIDE.md`](docs/github-kit/ORGANIZATION_GUIDE.md)
> for the recommended source + GitHub Actions setup.
